Valheim Namekeeper 0.4.8 by SuperNova.

This update brings the changes since the 0.3.10 repository snapshot:

- Three hidden, protected Namekeeper camps in the Meadows of newly generated worlds, with the classic hammer-built workshop available as an alternative server-controlled mode.
- Localized shop signs, interface, discovery messages and native map icons; an authenticated administrator command reveals shop positions only to its caller.
- A vanilla camp layout with rune stones, supplies, cleared ground, two animated pettable boars, an interactive bench and a table with decorative food.
- Hildir's original feeding bowl and turnip arrangement in 0.4.8, replacing the procedural carrot display. Original positions, rotations and scales are preserved together.
- Matching client/server versions and server-synchronized gameplay settings; existing camp positions, terrain, services, prices and item metadata are preserved.

Download **ValheimNamekeeper-0.4.8.zip** for both Thunderstore and r2modman. Its manifest includes `author: SuperNova`. Install the same version on every client and the server. The Source ZIP is for developers.

Compilation, 64 game-independent tests, 30 structural/native-contract checks and native meal geometry inspection passed. Final live-game visual and dedicated-server acceptance remain pending. The archive includes a Russian 0.4.8 test checklist; see the changelog for complete history.
