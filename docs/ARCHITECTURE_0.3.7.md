# Namekeeper 0.3.7 — завершение жестов штатным Animator

Кандидат сохраняет положение торговки и плавный вход в жесты из 0.3.6. Идентификаторы лавки и крыши, ZDO, положение, размеры, дверь, рецепты, мебель, цены и поведение сброса текста не меняются.

## Жесты торговки

Принудительный возврат после заданного таймера удалён. `Animator.Rebind()` сбрасывал всю модель; сохранение `AnimatorStateInfo.fullPathHash` в 0.3.6 тоже было ненадёжным: state hash обозначает состояние контроллера, а не конкретную позу, и переход обратно в него воспроизводил нежелательную лежачую фазу. Теперь код только плавно (0,18 секунды) входит в выбранное одноразовое состояние жеста через `CrossFadeInFixedTime`. Дальнейший выход к idle выполняет штатный Animator Controller игрока. Root motion остаётся выключенным.

Спокойное ожидание остаётся штатной базовой стойкой с опущенными руками. Реплика `Idle` по-прежнему не запускает жест и не влияет на анимационный переход.

## Сохранение функциональности

Тексты RU/EN, выбор языка игры, голосовые дорожки Хильдир, локальная визуальная модель игрока, торговый HUD, услуги и все постройки остаются как в 0.3.6. Не создаются новый сетевой NPC, ZDO или физические столкновения.

## Проверка

Сборка против локальных DLL Valheim и проверка ванильного манифеста выполняются отдельно. В игре нужно подтвердить, что каждый жест заканчивается прямым плавным возвращением в стойку без лежачей фазы; сценарий находится в `TEST_PLAN_0.3.7.md`.
