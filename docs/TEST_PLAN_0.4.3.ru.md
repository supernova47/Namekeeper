# Тест-план Namekeeper 0.4.3

Исправлена проверка администратора для `namekeeper_map`: сервер сопоставляет числовой ID игрока с ID из списка администраторов в платформенном формате, например `V_<SteamID>`. После завершения генерации локаций команда ищет позиции Namekeeper в общем списке сгенерированных локаций мира; для этого соответствующие зоны не обязаны быть исследованы или сохранены на диск.

## Проверка команды карты

- [ ] Обновить Namekeeper до 0.4.3 одновременно на dedicated-сервере и клиенте; перезапустить их.
- [ ] Убедиться, что сервер загрузил Namekeeper 0.4.3 и ID администратора остался в `adminlist.txt`.
- [ ] Подключиться своим администраторским аккаунтом, открыть игровую консоль и выполнить `namekeeper_map on`.
- [ ] Убедиться, что сервер отвечает `authorized=True`, а на личной карте появляются метки найденных лавок.
- [ ] Выполнить `namekeeper_map off`: временные метки должны исчезнуть.
- [ ] Проверить, что обычный игрок без прав получает отказ и координаты ему не передаются.
- [ ] Если команда сообщает, что точек нет, дождаться завершения генерации локаций при запуске сервера и повторить `on`. Изучение новых зон не создаёт пропущенные точки задним числом.

## Проверка журнала и лавок

- [ ] В серверном `BepInEx/LogOutput.log` проверить строку `Shop map reveal request ... authorized=True` и количество найденных точек.
- [ ] Если после завершения генерации сервер отвечает `authorized=True, locations=0`, текущий мир не содержит созданных записей лавок; нужно отдельно исправлять размещение и проверять его на новом тестовом мире.
- [ ] При нахождении координат проверить, что каждая метка ведёт к лавке с торговкой, кабаном и защитным куполом.
- [ ] Проверить Haldor-подобное обнаружение лавки и локализованное уведомление при приближении.
- [ ] Убедиться, что неподходящая версия Namekeeper на клиенте не подключается к серверу.
- [ ] В логах клиента и сервера не должно быть новых ошибок Namekeeper, Jötunn, RPC, `ZoneSystem` или `Minimap`.

## Что прислать при сбое

- [ ] Полный ответ игровой консоли после `namekeeper_map on`.
- [ ] Строку `Shop map reveal request` из серверного лога и версии модов на сервере и клиенте.
- [ ] Seed мира и отметку, исследовались ли новые зоны после запуска 0.4.3.
